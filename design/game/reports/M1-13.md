### 2. Recommend exact before/after values or justify no change; avoid speculative new systems — PASS

- First equipment drop and specialization unlock: both within their target bands as measured.
  **No change.**
- Boss readiness: **no change** to any `baseline.md` section 1-6 number. Justification (full detail
  in `design/game/economy/tuning.md`): boss-ready is not gated by a reward number — it is the exact
  cycle level 3 is reached, and the Tollkeeper is winnable at level 3 regardless of gear or
  specialization (verified by M1-12 down to the fully unequipped/unspecialized case). Any economy
  lever that delays this (slower XP/cycle, higher `xpToNext`) delays specialization unlock by the
  identical amount, since they are the same event in this engine — and specialization unlock is
  currently exactly on its own target. Slowing a correct number to compensate for a different
  system's stat balance is the speculative-fix pattern this task is scoped to avoid. Instead,
  `baseline.md` section 7's hand-derived hypothesis (level 4-5, 23-38 cycles) is corrected in place
  to the validated figure (level 3, 12 cycles), with the superseded estimate kept in a collapsed
  section for traceability, and the open "is this acceptable, or should the boss be harder"
  question is raised to the owner rather than decided unilaterally (see question block below).

### 3. Explain effects on offline rewards, loss streaks, boss readiness and viable specializations — PASS

See `design/game/economy/tuning.md` ("Effects of the no-change decision") for full detail:

- **Offline rewards:** unaffected (no reward number changed); this run's catch-up benchmark
  reconfirmed p95 6.69 ms (well under the 2000 ms provisional target) and the `recentCycles` bound
  held, matching M1-12.
- **Loss streaks:** 0 losses across all 72 swept runs (both builds) — the existing `0 XP/gold/drop
  on loss` rule is uncontested by any evidence gathered; no cushioning mechanic is warranted.
- **Boss readiness:** documentation correction only, per above; the thin combat margin (2 of 3
  heroes dying in the unequipped level-3 trace) is a combat-balance signal flagged to the owner, not
  acted on by this economy-scoped task.
- **Viable specializations:** all 8 real specialization combinations plus "unspecialized" won the
  boss at level 3 in the swept data from both builds, 0 losses in any combo. No reward number needs
  to favor or penalize any specialization at this gate.

## Unresolved issues / limitations

- **Open design question, not decided by this task:** is a boss win arriving at the exact moment
  specialization unlocks (with a thin HP margin if unequipped) acceptable for first playable, or
  should `content.md`'s Tollkeeper stats (or `combat.md`'s level-3 gate) be hardened to restore a
  real 20-40 minute separation? This is a scope/vision call outside `design/game/economy`'s write
  scope and outside this role's authority to decide alone — see the question block below.
- Both this task's and M1-12's measurements are single-machine (same Windows/i7-14700K dev box); no
  cross-machine variance has been measured for either the pacing sweep or the catch-up benchmark.
- The simulation still only sweeps from level 3 upward for boss attempts (per M1-12's note:
  combat.md's effective-action gate makes under-level-3 attempts strictly worse, and specialization
  isn't unlocked yet, so a sub-level-3 boss attempt was not and is not swept). This does not change
  the conclusion above since level 3 is already the earliest level reachable with a specialization
  choice.
